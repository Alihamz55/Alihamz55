# Panduan Jualan di Lynk (lynk.id/alidraws)

## Urutan blok
1. Banner (blok **Image**)
2. Produk berbayar terbaru (blok **Digital Product**, layout besar)
3. Sampel gratis (blok **Digital Product**, layout kecil)
4. Produk lama di bawahnya

## Isian Digital Product → Simple Template
- **Image:** thumbnail 1080×1080
- **Title:** `<Nama Ebook> untuk Anak <Jenjang> (<isi utama> + <bonus>)`
- **Allow Download:** aktif
- **Pricing produk berbayar:** "pay what you want" **MATI**, isi harga. Default Rp19.000, atau
  sesuaikan dengan jumlah halaman (sekitar Rp15–35 ribu).
- **Pricing sampel gratis:** "pay what you want" **NYALA**, Minimum 0, Suggested 0
- **Flash Sale:** mati (pakai nanti untuk promo, mis. Rp9.900 selama 3 hari)
- **Item Quantity / Limit:** mati
- **Question for customer:** kosongkan, atau satu pertanyaan opsional
  "Dari mana kamu tahu produk ini?"
